# Playwright Testing Academy

This repository contains Playwright tests and example scripts for the Playwright Testing Academy.

Contents:
- `learn_01.js` — example/learning script present in the workspace.

How to run (basic):

1. Install dependencies:

```bash
npm install
```

2. Run Playwright tests (if configured):

```bash
npx playwright test
```
